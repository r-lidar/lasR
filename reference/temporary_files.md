# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpqAbBsh/file22b03e8b23ad.shp"
templaz()
#> [1] "/tmp/RtmpqAbBsh/file22b03afd6697.laz"
```

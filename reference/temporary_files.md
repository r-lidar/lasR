# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpkcxRXA/file22a1711bdcc3.shp"
templaz()
#> [1] "/tmp/RtmpkcxRXA/file22a13b45a87e.laz"
```

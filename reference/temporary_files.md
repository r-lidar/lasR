# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/Rtmpkbcb4u/file22bf6623baa5.shp"
templaz()
#> [1] "/tmp/Rtmpkbcb4u/file22bf61aeed85.laz"
```

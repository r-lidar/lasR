# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpoWAJst/file22873936f70d.shp"
templaz()
#> [1] "/tmp/RtmpoWAJst/file2287109efb3c.laz"
```

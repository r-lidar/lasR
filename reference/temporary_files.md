# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpnhFzkD/file22797d1890c.shp"
templaz()
#> [1] "/tmp/RtmpnhFzkD/file22794aa79e7a.laz"
```

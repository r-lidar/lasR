# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/Rtmp8O2r5T/file21d44944996b.shp"
templaz()
#> [1] "/tmp/Rtmp8O2r5T/file21d46cbc5871.laz"
```

# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpmcxIja/file2239310d6fc0.shp"
templaz()
#> [1] "/tmp/RtmpmcxIja/file223949199e78.laz"
```

# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpxVjz5y/file21fd4ef1e252.shp"
templaz()
#> [1] "/tmp/RtmpxVjz5y/file21fd7f0241ed.laz"
```

# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/Rtmpozo1Os/file22185be199ca.shp"
templaz()
#> [1] "/tmp/Rtmpozo1Os/file22185e695271.laz"
```

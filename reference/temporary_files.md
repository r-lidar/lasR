# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpPkLmxB/file222d4e0437d4.shp"
templaz()
#> [1] "/tmp/RtmpPkLmxB/file222dd4d11c0.laz"
```

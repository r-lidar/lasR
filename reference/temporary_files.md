# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpHzMLKc/file230e13376051.shp"
templaz()
#> [1] "/tmp/RtmpHzMLKc/file230e7655d368.laz"
```

# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/Rtmpj40xB7/file22ab58346329.shp"
templaz()
#> [1] "/tmp/Rtmpj40xB7/file22abae6838f.laz"
```

# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpNQtePu/file226718fa7957.shp"
templaz()
#> [1] "/tmp/RtmpNQtePu/file22676e425755.laz"
```

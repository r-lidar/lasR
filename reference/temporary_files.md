# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpOZWUki/file228513dba66b.shp"
templaz()
#> [1] "/tmp/RtmpOZWUki/file22853c45e7c9.laz"
```

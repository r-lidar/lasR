# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpVtwaxc/file230f51b27d54.shp"
templaz()
#> [1] "/tmp/RtmpVtwaxc/file230f28cb9261.laz"
```

## Notes

This report was produced with `run_all.sh` on the combined COPC branch
(`lasR_git_sha` above, which is current `devel` plus the writer, the
multi-file merge and this harness).

### How to read the tables

- `lasR-default` is the legacy LASlib writer run at density `"normal"`, the
  same as `lasR-experimental`, while the legacy writer's own default is
  `"dense"`.
- Each writer ran once "cold" and three times warm. The machine has no
  passwordless `sudo`, so `DROP_CACHES=auto` did not drop the page cache: the
  "cold" figure is only the first of four runs.
- Every read scenario was run once per writer, against a local `httpuv` server
  on the loopback interface. Request counts and bytes are properties of the
  file; the wall times carry no network latency and no repeat to judge their
  spread.
- `R1` is a full read, `R2-dN` reads octree depths 0..N, and `R3` is a 50 m
  radius circle at the tile centre (393,856 points for every writer).
- In `R2-dN` the writers return different numbers of points, because each
  writer decides how many points a level holds. Bytes and wall time are
  therefore not like-for-like across writers in those tables; `bytes/point` is.

### Untwine crashed in two of four runs

The cold run and the third warm run of Untwine 1.5.1 ended with a segmentation
fault (exit status 139) after about 51 s, leaving a truncated output and its
temporary directory. The other two warm runs finished normally and their
output validates with `pdal info` (COPC, 45,243,335 points). `make_report.R`
keeps only runs with exit status 0, so the Untwine row is the median of two
warm runs and has no cold value. The cause was not investigated.

- The experimental writer has the shortest wall time and the lowest peak RSS
  of the six, in both presets.
- Its output is larger than that of `lascopcindex`, Untwine and the legacy
  lasR writer, and smaller than PDAL's. The legacy writer produces the
  smallest file.
- The four outputs of `lasR-experimental` are byte-identical (same md5), and
  so are the four of `lasR-experimental-dense`. The legacy writer's four
  outputs differ in size from run to run.

### LOD organisation

The experimental writer produces a depth-5 tree with about 2,800 nodes, like
PDAL and Untwine (2,099 nodes). `lascopcindex` and the legacy writer produce a
depth-4 tree with about 610 nodes. Density rasters per depth, a uniformity
table for all six writers and the multi-tile checks are in
`REPORT-LOD-MULTITILE-2026-09-30.md`.

### Read phase

- `R1`: the full read transfers between 247 MB (legacy) and 296 MB (PDAL); the
  experimental presets transfer 289 MB and 285 MB. Wall times are between
  18.3 s and 20.9 s.
- `R2-d0`: the experimental writer returns 65,567 points at depth 0 (100,000
  with the dense preset). PDAL returns 87,635, Untwine 192,536 and
  `lascopcindex` 334,402.
- `R3`: for the same 393,856 points, `lasR-experimental` transfers the fewest
  bytes (15.3 MB) in the shortest time (1.5 s). Untwine transfers 17.9 MB,
  the legacy writer 23.2 MB, the dense preset 24.0 MB, PDAL 28.7 MB and
  `lascopcindex` 47.7 MB.
